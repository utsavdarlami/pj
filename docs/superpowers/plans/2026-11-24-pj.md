# pj Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sourced zsh function `pj` that lists every folder any of five AI agents ran in, picks one with fzf, `cd`s there and starts a fresh agent session.

**Architecture:** One file `pj.zsh` with three layers: `_pj_scan` (raw `path\tagent\tepoch` lines from each agent's session files), `_pj_rows` (merge, filter, format), `pj` (fzf UI) → `_pj_act` (cd + launch). Every function reads `$HOME`, so tests point `HOME` at a fixture dir.

**Tech Stack:** zsh, `zsh/stat` module (`zstat`, portable mtime), grep, awk, jq, fzf.

**Spec:** `docs/superpowers/specs/2026-11-24-pj-design.md`

## Global Constraints
- Agents and launch commands: `claude`, `codex`, `gemini`, `pi`, `opencode`. Fresh session only, never resume flags.
- One row per folder; agent tags ordered newest-first; first tag = agent Enter launches.
- Keys: Enter = cd + launch last-used agent · ctrl-a = cd + choose agent · ctrl-d = cd only.
- Drop paths under `/tmp`, `/var/tmp`, the path `/`, and paths that don't exist as directories.
- Full scan on real data under 1s. No cache.
- Dependencies limited to fzf + jq (both installed). Linux + macOS; no `stat -c` / `stat -f`.
- `claude-repo` is not a git repo: no commit steps. Run `git init` first if you want history.

## Review Focus
1. Folder path containing spaces → appears as one row, cd works (tab is the only delimiter). Test in Task 2.
2. Session file with no `cwd` / empty file → silently skipped, no blank row. Test in Task 1.
3. Esc in fzf (empty selection) → no cd, no launch, returns 1. Test in Task 3.
4. Last-used agent no longer installed → still cd, print `pj: <agent> not found`, return 1. Test in Task 3.
5. opencode global project with `worktree: "/"` → dropped. Test in Task 2.

### Task 2: Merge and format rows

**Files:** Modify `pj.zsh`, `test_pj.zsh`

**Interfaces:**
- Consumes: `_pj_scan`
- Produces:
  - `_pj_ago <epoch> <now>` → `5m` (<1h), `3h` (<1d), `2d` (<7d), `3w` (<30d), `4mo` otherwise.
  - `_pj_rows [now]` (default `$EPOCHSECONDS`, needs `zmodload zsh/datetime`) → lines `path<TAB>display<TAB>agents`, newest folder first.
    - `display` = `printf '%-28s %-30s %s'` of basename, parent with `$HOME`→`~`, tags `claude·2h codex·3d`.
    - `agents` = space-separated agent names, newest first.
  - Merge per (path, agent) keeping max epoch (awk); folder recency = its max epoch.

### Task 3: Picker, action, install

**Files:** Modify `pj.zsh`, `test_pj.zsh`, `~/.zshrc` (append one line)

**Interfaces:**
- Consumes: `_pj_rows`
- Produces:
  - `_pj_act <key> <row>`: empty row → return 1. `cd` to field 1. `ctrl-d` → return 0. `ctrl-a` → agent = `print -l <row agents> <rest of PJ_AGENTS installed> | fzf --prompt='agent> '` (Esc → stay in dir, return 0). Otherwise agent = first of row agents. Not on PATH → `print -u2 "pj: $agent not found"`, return 1. Else run `$agent`.
  - `PJ_AGENTS=(claude codex gemini pi opencode)`
  - `pj`: `out=$(_pj_rows | fzf --delimiter=$'\t' --with-nth=2 --expect=ctrl-a,ctrl-d --no-sort --prompt='pj> ' --header='enter: new session · ctrl-a: pick agent · ctrl-d: cd only')`; key = line 1, row = line 2; `_pj_act "$key" "$row"`.

- [ ] **Step 1: Add tests** (run in subshells so `cd` doesn't leak; stub agent with a function `claude() { print launched-claude }`):

```zsh
ok "$( (_pj_act "" "") ; print $?)" "1" "act: esc does nothing"
ok "$( (_pj_act ctrl-d "$HOME/proj/a"$'\tx\tclaude'; pwd) )" "$HOME/proj/a" "act: ctrl-d cd only"
ok "$( (_pj_act "" "$HOME/proj/a"$'\tx\tclaude') )" "launched-claude" "act: enter launches last agent"
ok "$( (_pj_act "" "$HOME/proj/a"$'\tx\tnosuchagent' 2>&1; pwd) )" "pj: nosuchagent not found
$HOME/proj/a" "act: missing agent still cds"
```
