# pj — jump back into any AI-agent project

## Why
I use five coding agents (Claude, Codex, Gemini, pi, opencode) across many repos. I want one
command that lists every repo any of them touched and drops me back in with a new agent session.

## Goals
- `pj` → fzf list of projects, most recent first → Enter = `cd` there + start a **fresh** session of the last-used agent.
- One row per **folder**; agents shown as tags with time since last use.
- Reads each agent's own session files. No hooks, no daemon, no database.

## Non-goals
- Resuming previous sessions, Windows support, GUI, session browsing/cleanup, usage stats.

## Anti-goals
- Slow startup (>1s) or rows full of junk sandbox folders.

## Approaches considered
| | Trade-off |
|---|---|
| **B. zsh function + fzf (picked)** | ~50 lines, fzf (+ sqlite3 for opencode) already installed, can `cd` the current shell. Linux/macOS only. |
| A. Python CLI | Cross-platform, but can't `cd` the parent shell; more code. |
| C. Vicinae/Raycast plugin | Polished, but no Windows and still has to spawn a terminal. |

Picked B: simplest, and being a sourced shell function it can actually change your directory.

## Data sources (verified on this machine)
| Agent | Path → cwd | Last used | Launch cmd |
|---|---|---|---|
| claude | `~/.claude/projects/*/*.jsonl`, first `"cwd"` (dir names are lossy, don't decode) | newest jsonl mtime | `claude` |
| codex | `~/.codex/sessions/**/*.jsonl`, line 1 `payload.cwd` | file mtime | `codex` |
| pi | `~/.pi/agent/sessions/*/*.jsonl`, line 1 `cwd` | file mtime | `pi` |
| gemini | `~/.gemini/tmp/*/.project_root` | `chats/` mtime | `gemini` |
| opencode | `~/.local/share/opencode/opencode.db` table `project` (non-archived), `worktree`; skipped if no `sqlite3` | `max(time_updated, time_active)` ms | `opencode` |

## Behaviour
- Emit `path<TAB>agent<TAB>epoch` per source, merge per path, sort by newest.
- Drop paths under `/tmp`, `/var/tmp`, and paths that no longer exist.
- Row: `name  ~/parent  claude·2h codex·3d …`
- Keys: **Enter** cd + new session of last-used agent · **ctrl-a** cd + choose agent (new session) · **ctrl-d** cd only.
- No resuming old sessions; add a ctrl-r resume key later if wanted.

## Location
`~/Desktop/Workspace/claude-repo/pj.zsh`, sourced from `~/.zshrc`.
